# 目录与内置资源

模板与资源使用两棵独立目录树。数据库迁移会把升级前仍在根目录的模板放入“图表分析”或“未分类”，把资源按类型和用途放入下列目录。迁移不会覆盖用户已经选择的目录。

## 模板目录

- `/图表分析`：柱图、折线图、桥图、饼图、双轴图、面积图和散点图等图表型模板。
- `/通用叙事`：封面、章节、结尾等通用页面。
- `/经营与财务`：经营指标、利润、预算和情景分析。
- `/项目管理`：项目概览、里程碑、甘特图、进度和依赖关系。
- `/战略与销售`：市场、客户组合、决策和销售提案。
- `/组织与协作`：团队、组织结构和 RACI。
- `/专业分析`：状态表等专题分析。
- `/未分类`：升级前没有目录且无法归入内置分类的模板。

模板库首页和“我的文稿 → 新增页面 → 导入模板”提供同一棵目录树和名称搜索。选择 `/` 时展示全部可见模板，选择具体目录后只在该目录内检索。

## 资源目录

- `/图标/经营分析`、`/图标/协作与状态`、`/图标/商品零售`
- `/图标/人物角色`、`/图标/数据技术`
- `/矢量图/商业表达`、`/矢量图/商品零售`
- `/矢量图/人物角色`、`/矢量图/数据技术`
- `/图片/封面背景`、`/图片/商品摄影`、`/图片/办公商务`
- `/图片/物流供应链`、`/图片/科技制造`、`/图片/可持续发展`

内置资源当前包含 62 个图标、38 个彩色矢量图和 12 张图片。通用线性图标来自 Lucide，人物头像来自 Twemoji；数据技术标识的单色版本来自 Simple Icons，彩色版本来自 Devicon。照片使用可再分发来源。每项资源的来源 URL、许可证、本地 SHA-256 和修改说明记录在 `backend/fixtures/assets/manifest.json`，完整许可证及分批导入记录放在 `backend/fixtures/assets/licenses/`。

数据技术标识用于在架构图和汇报中识别第三方项目，不表示这些项目对 SlideBI 的认可。Simple Icons 和 Devicon 的集合许可证不授予商标权，使用者仍需遵守对应项目的商标规则；资源清单同时记录品牌官方来源和固定版本，便于发布前复核。

迁移只归档同一 owner 下名称、类型和文件 SHA-256 均相同的图片副本。归档不删除原文件，已有页面和模板仍可读取这些资源。名称相似但文件内容不同的资源不会被自动清理。
