# Slide Report v0.1.1

发布日期：2026-10-08

这是首个公开版本的可复现性补丁。功能范围与 v0.1.0 保持一致。

## 修复

- 测试使用的 Data Spec、页面和导出 fixtures 全部纳入源码仓库，不再引用仓库父目录；
- GitHub Actions 在全新 checkout 中可完成类型检查、564 项测试和生产构建；
- E2E 的辅助登录和只读用户场景支持 `SLIDEBI_E2E_BASE_URL`；
- 模板全屏编辑工作区增加稳定的 dialog 语义，便于键盘、辅助技术和自动化测试识别。

完整功能清单和已知限制见 [v0.1.0 发布说明](v0.1.0.md)。
