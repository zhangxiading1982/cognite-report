# Slide Report v0.1.0

发布日期：2026-10-08

这是 Slide Report 的第一个公开源码版本，建立可复现的开发环境、数据库迁移、内置样例、测试门禁和版本化文档。

## 功能范围

- 多页文稿创建、页面编辑、导航配置、预览和 PPTX 导出；
- 商业模板目录、完整页面预览、模板数据和 owner 编辑；
- 人工/Mock BI 数据集、Schema、版本、回滚和图表预览；
- 图片、图标和 SVG 资源目录、加工和页面插入；
- 管理员/普通用户、owner 权限以及公开/私有可见性；
- 52 个内置模板、118 个内置资源和可重复生成的样例数据。

## 工程与文档

- React 19 + Vite 前端、Express 5 后端、PostgreSQL 16 和共享 presentation 引擎；
- 一键环境检查、数据库初始化、数据种子和发布检查脚本；
- Vitest/Supertest/PostgreSQL 集成测试及 Playwright 浏览器验收；
- 完整的背景、领域、架构、数据库、配置、开发、测试和使用文档。

## 已知限制

- 真实 BI Studio Data Spec 和 DAX API 尚未接入，当前使用 Mock。
- 生产身份认证、对象存储、密钥管理和部署方案尚未提供。
- `pptxgenjs@4.0.1` 间接依赖的 `image-size` 存在两个拒绝服务公告；输入会先经 sharp 解码、重编码并限制为 PNG/JPEG，仍需等待上游修复。
- 项目所有者仍需选择开源许可证；在许可证加入前，公开仓库源码不自动授予复制、修改或再分发权利。

升级和安全边界见[开源准备审查](../open-source-readiness.md)与[安全说明](../../SECURITY.md)。
