# 领域概念

## 身份与访问

- **用户（User）**：登录主体，角色为 `admin` 或 `user`。
- **Owner**：文稿、模板、数据集和资源的所有者。只有 owner 可以修改或删除对象。
- **可见性（Visibility）**：`private` 只允许 owner 访问；`public` 对所有已登录用户可见。公共对象的非 owner 可以预览，文稿还可以导出。
- **目录（Folder）**：模板、数据和资源各自拥有独立目录树。目录只组织对象，不改变对象内容。

## 汇报内容

- **文稿（Content/Deck）**：面向一次汇报的多页容器，保存页面顺序、章节、导航和交付设置。
- **页面（Slide/Page）**：16:9 的可编辑画布，包含文字、资源、形状、表格和图表。页面形成后独立存在，不依赖模板继续渲染。
- **页面修订（Slide Revision）**：自动保存产生新的当前修订；用户执行“保存”时形成文稿快照，用于回溯和稳定导出。
- **预览（Preview）**：在导出前冻结页面修订和数据版本，确保 PPTX 生成过程中内容不漂移。

## 可复用内容

- **模板（Template）**：商业汇报最佳实践，包含业务背景、适用场景、完整页面样例和模板自带数据。文稿导入模板时复制页面与配套数据。
- **模板版本（Template Version）**：模板每次保存的不可变版本。旧文稿不会因模板后续编辑而改变。
- **资源（Asset）**：页面可引用的图片、图标和矢量图。加工操作生成预览或另存副本，不覆盖原始文件。
- **组件片段（Fragment）**：从页面对象保存的个人复用片段，不复制业务数据。

## 图表数据

- **Data Spec**：图表输入契约，由一张或多张结果表、字段 Schema、数据行、查询元数据和来源信息组成。
- **数据集（Dataset）**：数据管理中的稳定对象，以 `d_` 开头的 `dataId` 对外识别。名称、表名、字段显示名和数据可以更新。
- **数据快照（Data Snapshot）**：一次数据内容的不可变存储。它是数据集版本和历史导出的底层实现，不是用户需要手工管理的独立业务对象。
- **数据集版本（Dataset Version）**：数据集更新或回滚后产生的历史版本，界面保留最近六版供回滚。回滚会发布一个新的当前版本。
- **表 ID / 字段 ID**：引用使用稳定 ID，显示名称可以修改。图表绑定不会因表名或字段名调整而失效。
- **刷新配置（Refresh Config）**：按表保存数据来源、模型 ID 和具名 DAX 查询。BI Studio 数据可刷新；人工导入没有刷新入口。

## 导出

- **导出任务（Export Job）**：持久化的异步任务，记录冻结输入、状态、失败原因和生成文件。
- **PPTX / Manifest**：导出物及其机器可读清单。删除导出记录时同步删除对应文件。

关键约束是“编辑使用当前数据，历史导出使用冻结数据”。这使数据集能够持续刷新，同时保证已经生成的汇报可以复现。
