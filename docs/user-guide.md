# 使用说明

## 登录与权限

本地初始化后使用 README 中的演示账号登录。对象分为私有和公开：owner 可以编辑、移动和删除；其他用户只能查看公开对象，公共文稿还可导出。管理员可在顶部用户入口维护账号和角色。

## 管理图表数据

1. 打开“数据管理”，在左侧目录树选择目录。
2. 新建数据集，选择人工录入或 BI Studio 导入。
3. 人工录入时维护表名、字段 Schema 和表格数据；表和字段的内部 ID 保持稳定。
4. 在“图表预览”中选择可用图表类型并配置字段角色。
5. 后续修改会形成数据集新版本；历史中可回滚最近六版。

被页面引用的数据集不能直接删除。修改当前数据后，引用它的页面会按最新数据重新渲染；已经冻结的导出仍保留原版本。

## 使用模板和资源

模板库展示完整样例、业务背景、适用场景和配套数据。owner 可以修改模板基础信息、页面和样例数据。模板维护页不直接创建文稿页面；请在文稿编辑器中使用“新增页面 → 导入模板”。

资源库支持图片、图标和 SVG。owner 可以维护名称、目录和可见性，并对资源做去底色、换底色或矢量颜色调整。加工结果可下载或另存为新资源，原件不会被覆盖。

## 编辑多页文稿

1. 在“我的文档”中新建文稿。
2. 新增空白页或导入模板。导入模板会直接使用模板自带数据。
3. 用页面工具栏插入文字、资源、图表、表格或形状。
4. 选中对象后在右侧维护内容、样式和数据。图表可重新绑定可见的数据集。
5. 画布编辑自动保存；工具栏“保存”会形成用于历史回溯的文稿快照。
6. 按需配置封面、导航、章节和页码，并在文档预览中逐页检查。

模板自带图表数据默认是页面私有数据。需要长期维护时，使用“copy 到数据管理”并选择目录；复制后页面绑定新数据集。

表格支持正文与表头字体、字号、对齐、底色和分隔线设置，也可强调首列、末行，并按正负值显示上升/下降颜色。表格的 SVG 预览与 PPTX 原生表格使用同一份列宽和单元格样式。

折线连接器的端点可吸附到形状四边中点。选中折线后，黄色控制点对应一条可移动的中间线段；拖动后保存实际拐点，连接形状移动时仍保持端点吸附和已调整的中间路径。

## 导出 PPTX

在文稿工具栏中选择“导出”，系统会创建持久任务。任务完成后浏览器直接下载 `.pptx` 文件，也可在“导出记录”按文稿名称查找、重新下载或删除。删除记录会同时删除历史导出文件。

浏览器预览与 PPTX 使用同一编译结果，但字体渲染仍取决于打开文件的电脑。默认字体为黑体（`SimHei`）；目标电脑应安装文稿所选字体。
